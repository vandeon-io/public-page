# Vandeon website — Astro

The marketing site rebuilt on [Astro](https://astro.build). Static output, zero
JS shipped except the animated hero illustration (a small React island).

## Run locally

```bash
npm install
npm run dev        # http://localhost:4321
```

## Build for production

```bash
npm run build      # outputs static site to ./dist
npm run preview    # preview the built site
```

Deploy `dist/` to any static host (Netlify, Vercel, Cloudflare Pages, GitHub
Pages, S3, …). No server required.

## Where things live

| Path | What |
|------|------|
| `src/consts.js` | **Edit your links here** (app / LinkedIn / Telegram), the social-platform copy, and SEO defaults. |
| `src/styles/tokens.css` | **Design tokens — the single source of truth** (color, type, radii, motion). |
| `src/styles/global.css` | Component styling (imports `tokens.css`). |
| `docs/design-system.md` | UI implementation guide for the site and the app. Brand identity (voice, logo, color meaning) lives in the Vandeon design system artifact; token values in `tokens.css`. |
| `astro.config.mjs` | Astro config — sets the production `site` URL and the sitemap integration. |
| `src/layouts/Base.astro` | `<head>`: SEO meta (canonical, Open Graph, Twitter, JSON-LD), fonts, reveal-on-scroll script. |
| `src/pages/index.astro` | Landing page (hero, right-sized, who it's for, CTA). |
| `src/pages/_follow.astro` | Follow page (social cards) — **currently hidden** (see below). |
| `src/components/` | Nav, Footer, SocialCard, FitMeter (static) + HeroViz (React island). |
| `public/` | Served as-is: `robots.txt`, `favicon.svg`, `og.png`, app icons, `site.webmanifest`. |
| `scripts/gen-og.mjs` | Regenerates the OG share image + app icons (`npm run gen-og`). |

## Changing the hero illustration

In `src/pages/index.astro`:

```astro
<HeroViz client:load variant="flow" accent="var(--accent)" />
```

`variant` can be `"flow"` (default), `"console"` (dark), or `"blueprint"` (light line-art).

## Changing the accent color

One spot: `src/styles/tokens.css` → `:root { --accent: … }`. It drives everything,
including the hero illustration (which reads `var(--accent)` directly). If you ship a
new share image, also update the mirrored color in `scripts/gen-og.mjs` and re-run it
(`npm run gen-og`).

## SEO & metadata

Configured and ready out of the box:

- **`site`** in `astro.config.mjs` is set to `https://beta.vandeon.io` — drives canonical
  URLs, absolute Open Graph image URLs, and the sitemap. Change it if the domain changes.
- **Sitemap** via `@astrojs/sitemap`, generated at build (`dist/sitemap-index.xml`).
- **`public/robots.txt`** allows crawling and points to the sitemap.
- **`Base.astro`** emits per-page title/description, canonical, Open Graph, Twitter
  cards, and Organization JSON-LD. Pages pass `title`/`description` (and an optional
  `image`) as props.
- **Share image / icons:** `public/og.png` (1200×630) + favicon and app icons,
  regenerated by `npm run gen-og`.

> `@astrojs/sitemap` is pinned to `3.2.1` — newer 3.x requires Astro 5 and breaks the
> build on this Astro 4 project. Keep it pinned until Astro is upgraded.

## The follow page (currently hidden)

`/follow` is disabled until the LinkedIn/Telegram channels are live. The page file is
`src/pages/_follow.astro` — the leading `_` tells Astro not to build a route for it —
and the nav/footer/CTA links to it are commented out (so it also stays out of the
sitemap). **To restore:** rename it back to `follow.astro` and uncomment the `follow`
links in `Nav.astro`, `Footer.astro`, and the CTA in `index.astro`.
